# Brand — Onchain Time Builder Sprint

Status: active

## Direction

An editorial, technical learning experience inspired by the supplied Solana Architecture reference. The site should feel like a focused builder briefing rather than a generic event landing page.

## Palette

- Background: `#0d0a17`
- Surface: `#191426`
- Raised surface: `#231b34`
- Text: `#f6f3fc`
- Muted text: `#bfb6cf`
- Border: `#40364f`
- Primary purple: `#baa0ff`
- Success green: `#88e3b8`
- Warm accent: `#f4cf84`
- Error red: `#ff9caa`

## Typography

- UI and display: Geist Sans
- Labels and numbers: Geist Mono
- Editorial emphasis: Georgia italic

## Voice

Direct, curious, builder-first, and specific. Prefer concrete outcomes and active verbs. Avoid startup clichés and prize-led language.

## Visual language

- Dark, full-bleed surfaces with thin borders
- Large compressed headlines with editorial italic emphasis
- Monospace labels, dates, progress markers, and technical annotations
- Restrained purple and green accents
- Motion only when it explains progress, iteration, or state
